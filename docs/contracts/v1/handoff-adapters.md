# Authentication adapters — Foxlin Industries

Source-only E1-H models six existing /v1/auth/handoffs QR lookup/completion and desktop-launch/mobile-push/qr/provider-choice routes. Use current original-RP backend relay authentication, never config secrets in native/browser clients. Anonymous lookup401 discloses no session; locator possession is not a Human grant. Lookup exposes only bounded continuation metadata to the original RP. Locator qr_32lowerhex is an opaque unpredictable GUID encoded as32 lowercase hex characters, exact session/RP binding and session expiry, and is available only in pending_qr_scan. Terminal/consumed/invalidated/restarted locators404; no SQL hydration. QR exit invalidates the old locator, reentry creates a new one. Repeated pending lookup supplies no signature or token.

QR completion reuses exact G1 current owner-approved ML-DSA proof, original Human/device/native registration/key/epoch/RP/app/tenant/environment/callback/expiry/generation. Known-owned failed completion is failed or quarantined even at early validation; stale proof cannot retry. Core and QR completion serialize through canonical authority admission; only one result may be consumed. Existing prepared authority must remain current before any adapter descriptor/transition.

Path commands accept empty body or{} only. They preserve challenge, signed context, scopes/roles, original identity and expiry; no callback/URI overrides or redirects. Generated aegir://auth/desktop or/mobile URI carries sessionId,mode and optional entry only. Its construction does not prove OS association/activation. The App descriptor parser accepts generated mode or legacy returnMode, never both, validates bounded URI/QR metadata, rejects userinfo/port/fragment/path normalization/unknown fields. Parsing a legacy oidc_bridge descriptor is metadata compatibility only; server creation still only accepts aegir_native. API locator syntax is stricter than bounded legacy opaque descriptor identifiers.

Mobile-push is path selection pending_mobile_push with X-Aegir-Push-Delivery:not-supported. No queue/APNs/FCM or actual delivery exists. Provider-choice selects offered aegir/google/facebook display metadata only (bounded list16 in G completion, provider32/identity256 at selection); selectedIdentity never becomes the authenticated Human, new scopes or roles. No OAuth/OIDC provider exchange is implemented.

All adapters bound UTF8 JSON requests and serialized responses to32768bytes; unique known fields, depth12/objects32/arrays16, no Content-Encoding/query parameters. Errors are sanitized and responses no-store/no-referrer. Capacity refusal quarantines unsafe touched work without pruning history. Lost response is ambiguous/unavailable, never success/Abort; restart requires new ceremony. Original G one-result/epoch/privacy guards and earlier contract anchors remain. Source HTTP contracts apply to all five SDK ecosystems; versions/methods/publication unchanged.
