# Aegir authorization/RBAC Skill — unreleased source contract

Foxlin Industries. E2-C4 adds the API-only `POST /v1/skills/v2/authorization-inspection` operation `application.group.authorization.inspect` for `application.group.authorization-inspection.read`. Exact source-bound execution and independent-review receipts govern acceptance; implementation alone is not acceptance.

The operation observes whether the original consenting Human currently has one exact `read` or `write` permission on the selected organization/group/application. The inspecting Human must independently hold current non-platform scoped administrative inspection authority, active staff relationship and the original current administration session. Agents require an exact approved installed Skill, fresh consent, current root/child ancestry, current credential/policy/approval/install state and finite reserved uses. Old unrelated grants do not acquire this capability.

The reviewed built-in identity is `aegir.authorization.scoped-inspection`, adapter `foxlin.builtin.authorization-inspection.v1`, profile `aegir.c4.builtin-authorization-inspection/v1`. Input/output schemas are `aegir.skill.authorization-inspection-input/v1` and `aegir.skill.authorization-inspection-output/v1`. Actual loaded Auth assembly bytes, immutable manifest/version, approval and installation pins bind the adapter. Descriptions are inert; no arbitrary code loads.

The [strict contract](contracts/e2-c4/openapi.json) requires all12 request fields: `action`, `operationId`, `skillKey`, `skillVersion`, `manifestDigest`, `adapterDigest`, `resourcePolicy`, `resourceAlias`, `scope`, `operation`, `targetPrincipalId`, `permission`. The target equals the original Human; permission is exactly `read` or `write` and is bound by the new exact consent domain. An inspection result is an observation at its authorization point, never a durable access ticket or permission grant.

A current application license and business membership/policy determine the observed business result. They are distinct from the authority to inspect: their removal can yield `Denied` while inspecting authority remains current. Losing the scoped administrative source, relationship, session or its current authority refuses inspection. The conservative supported profile has at most32 retained application policies and no active policy belonging to another group. Such multi-group profiles yield generic `Unsupported` rather than intersecting an app-wide permission union. No foreign role graphs, principal identifiers, membership lists or private credentials are returned. Invalid/unverifiable current graph state yields refusal or `Indeterminate`.

The bounded result contains only schema, original opaque alias, operation, `principalScope=consenting-human-only`, requested permission, decision/reason, `authority=canonical-current-engine`, `observationOnly=true`, `authorityGranted=false`. It cannot modify roles, memberships, credentials or administrative sessions. Canonical alias bookkeeping, finite uses and immutable audit may persist. Protected business operations must independently revalidate authority.

The .NET source binding `AegirAuthorizationSkillApiClient` provides `InspectAsync` and explicit `ReconcileAsync` for an immutable `AuthorizationInspectionRequest`, including expected grant, exact target and permission. It has bounded HTTPS/body/deadline checks and no redirects, cookies, proxies, retries or Human fallback. Preserve the same operation identity after timeout/lost response. Exact replay never rediscloses private output. Status exposes only nonsecret committed/unknown truth and the private server commitment; missing evidence never means Abort. Node/TypeScript, Python, Java and Go use the raw HTTP contract only; no new typed four-language API is claimed.

C4 deployments explicitly use trusted operational state `RbacSourceIntegrity:State=EnrolledRequired`. Independently retained source fingerprints and unresolved root obligations protect reviewed current-source transitions and restoration under the documented trust assumptions. The initial marker is not per-mutation freshness: simultaneously rolling back every independent anchor/configuration is not universally detected. Preserve the required operational state and current independent truth separately from mutable SQL. Total scan/sort work grows with retained source records; fixed row-digest pages bound materialization, not production scale.
