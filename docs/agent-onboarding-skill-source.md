# Foxlin Industries — Agent onboarding Skill source integration

Unreleased source-only C6 preparation contract; native adversarial qualification is pending. Package versions and publication status are unchanged. The .NET integration source adds AegirAgentOnboardingSkillApiClient.PrepareAsync and ReconcileAsync. Other languages may use the documented raw HTTP contract; no typed cross-language parity is claimed.

Use the real current Agent key and exact installed ags2 root/child reference with genuine current Human inspection consent, reviewed manifest/artifact, policy, scoped organization/group and owned application. The candidate has exactly name, identityClass, identityReference, credentialCustody and an explicit nonempty capabilities set. All fields are consent-bound. The client requires HTTPS, suppresses secret-bearing response bodies, disables redirects/cookies/proxy and bounds parsing. It never retries automatically. Ambiguous failures require explicit reconciliation of the original immutable operation ID.

ConfigurationValidated means only the inspected canonical registration configuration is supported. Identity uniqueness is not reserved. Existing identities, including revoked identities, cannot be adopted. Foreign/missing/application-unbound references have the same unavailable classification. Display names are labels, not unique identities. No identity, proposal, approval, credential, group membership or delegation authority is created. Provider/model/lifetime remain uninspected; actual provisioner authorization, custody and issuance-time identity/capacity verification remain separate prerequisites. Never treat preparation as a Developer agent:write grant or Human creation approval.

Preserve exact operation IDs across reconciliation. A duplicate does not return private preparation metadata again. Missing evidence is Unknown/recovery-required, never inferred Abort. Source-bound C6 acceptance evidence governs supported execution; this document does not authorize publication or production release.
